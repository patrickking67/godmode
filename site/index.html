Why Godmode

One coherent surface, not twelve overlapping ones.

Godmode fuses the best ideas across the ecosystem into a single opinionated plugin you install once, in either engine, with no per-repo setup grind.

  • Many plugins, overlapping commands

    One plugin, one command surface, one mental model across both engines.

  • Memory that disappears each session

    Hybrid global and per-project memory is on the roadmap, auto-injected on session start.

  • The same setup grind every new repo

    One marketplace install wires the same commands and servers into every repo.

  • MCP servers configured one at a time

    A curated ten-server no-auth bundle, pre-wired and opt-out, not opt-in.

Commands

Nine deific commands, identical in both engines.

Authored once in a single source and emitted as one skill that Claude Code and Codex both load.

Loading commands. The full list lives in data/godmode.json: revelation, gospel, prophecy, genesis, summon, judgment, sanctify, exorcise, and covenant.

Five subagents and three automatic hooks.

Auto-discovered on install. Codex has no equivalent surface, so it gets the nine skills and ten servers.

Connectors

Ten bundled no-auth MCP servers.

Docs, code intelligence, browser automation, and cloud. No API keys: HTTP endpoints are public and stdio servers run through npx.

Loading connectors. The bundle: Context7, Microsoft Learn, AWS Knowledge, Cloudflare Docs, Keeper Docs, DeepWiki, grep.app, Playwright, Chrome DevTools, and Azure.

Install

One marketplace install, either engine.

Requires Node 22 or newer and the Claude Code or Codex CLI. No daemon, database, or build step.

The nine skills and all ten MCP servers come wired in.

/plugin marketplace add patrickking67/godmode
/plugin install godmode@godmode

The skills appear in your slash menu and the bundled servers load automatically from the plugin's .mcp.json. No separate MCP setup on Claude Code.

The nine skills and all ten MCP servers come wired in.

codex plugin marketplace add patrickking67/godmode
codex plugin add godmode@godmode

The plugin points Codex at the same .mcp.json, so codex mcp list shows the servers after install. Want the servers without the plugin? A clone includes plugin/codex-mcp-setup.sh.
